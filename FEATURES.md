# Reflecta - Prioritized Feature List

## P0 - Essential (High Impact, Foundation)

| Feature | Description |
|---------|-------------|
| **Anonymous mode** | Option to hide card authors during retro |
| **Board sharing controls** | Public/private boards, password protection |
| **Facilitator role** | Lock/unlock voting, reveal cards, control timer |
| **Keyboard shortcuts** | Quick add card, navigate, vote (n, v, Enter) |

## P1 - High Value (User Retention)

| Feature | Description |
|---------|-------------|
| **Action items** | Convert cards to action items with assignee |
| **Board archiving** | Archive completed retros, searchable history |
| **Card reactions** | Quick emoji reactions beyond voting |
| **Markdown support** | Bold, italic, links in cards |
| **Dark mode** | Theme toggle |

## P2 - Collaboration (Team Features)

| Feature | Description |
|---------|-------------|
| **Teams/Workspaces** | Group boards by team |
| **User presence** | Show who's online, typing indicators |
| **Comments on cards** | Threaded discussion |
| **Card linking** | Link related cards across columns |
| **Duplicate board** | Clone board as template |

## P3 - Analytics & Insights

| Feature | Description |
|---------|-------------|
| **Retro summary** | AI-generated summary of themes |
| **Trends dashboard** | Track recurring topics over time |
| **Sentiment analysis** | Mood tracking across retros |
| **Export to Slack/Email** | Share summary with team |

## P4 - Integrations

| Feature | Description |
|---------|-------------|
| **Jira integration** | Create tickets from action items |
| **Slack integration** | Notifications, create boards from Slack |
| **GitHub integration** | Link cards to PRs/issues |
| **Calendar integration** | Schedule recurring retros |

## P5 - Nice to Have

| Feature | Description |
|---------|-------------|
| **Custom templates** | Users create/save own templates |
| **Icebreaker games** | Built-in retro games/activities |
| **Confetti/celebrations** | Fun animations for milestones |
| **Mobile app** | Native iOS/Android |
