# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-25

### Added

- Real-time collaborative retrospective boards with WebSocket synchronization
- Customizable columns for organizing feedback
- Sticky note cards with drag-and-drop functionality
- Real-time voting system
- Card grouping feature for combining related items
- Discussion timer with start/stop/reset controls
- Pre-built templates:
  - Start/Stop/Continue
  - Mad/Sad/Glad
  - 4Ls (Liked, Learned, Lacked, Longed For)
  - Sailboat (Wind, Anchor, Rocks, Island)
  - What Went Well / What Didn't
  - KALM (Keep, Add, Less, More)
- Export functionality (PDF, CSV, JSON)
- REST API for board management
- WebSocket events for real-time updates
- SQLite database storage
- Docker support for deployment
- Fly.io and Render deployment configurations
